════════════════════════════════════════════════════════════════════════════════
PASO 3: CONECTAR HARDWARE
════════════════════════════════════════════════════════════════════════════════

DEDOS (MG995) en GPIO 23:
  Rojo (5V) → VIN
  Negro (GND) → GND
  Amarillo (Señal) → GPIO 23

MUÑECA (SG90) en GPIO 17:
  Rojo (5V) → VIN
  Negro (GND) → GND
  Amarillo (Señal) → GPIO 17

Fuente: 5V @ 2A mínimo

════════════════════════════════════════════════════════════════════════════════
MAPEO DE CONTROL (v2.0)
════════════════════════════════════════════════════════════════════════════════

Predicción 1 (Mano DERECHA):
  → DEDOS: Cerrados (PWM 120, cierra puño)
  → MUÑECA: Posición inicial (PWM 90, no participa)

Predicción 0 (Mano IZQUIERDA):
  → DEDOS: Posición inicial (PWM 30, los retrae el resorte)
  → MUÑECA: Pronación (PWM 60)

Cada clase comanda un solo servo; el otro vuelve a su posición inicial.

TROUBLESHOOTING RÁPIDO
════════════════════════════════════════════════════════════════════════════════

❌ Error .fdt not found
→ CONVERTIR_CDT_A_SET('archivo.cdt') falla
→ Verifica que EEGLAB está instalado

❌ COM3 no se abre
→ Device Manager: ESP32 conectado a COM3?
→ Cierra Serial Monitor de Arduino IDE
→ Reinicia MATLAB

❌ Mano no se mueve
→ Serial Monitor: ¿Recibe mensajes del ESP32?
→ Verifica voltaje en pines servo (5V)
→ ¿Código cargado correctamente? (Setup message en Serial Monitor)
