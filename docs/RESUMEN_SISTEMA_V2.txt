OBJETIVO DEL PROYECTO:
  Implementar un sistema BCI offline que clasifique imagenes motoras de manos
  (izquierda vs derecha) y controle una mano robótica humanoide de 6 DOF.

│                                                                              │

│     ↓                                                                        │

│     ↓                                                                        │
│  4. EXTRACCIÓN DE CARACTERÍSTICAS                                           │
│     ↓                                                                        │
│  Welch PSD (3 canales, banda 13-30 Hz Beta)                                │

│  → Vector de 9 características                                              │
│     ↓                                                                        │
│  5. NORMALIZACIÓN (Z-Score)                                                │
│     ↓                                                                        │
│  Media y desviación estándar guardadas (mu_norm, sigma_norm)               │
│     ↓                                                                        │
│  6. MODELO DE RED NEURONAL                                                  │
│     ↓                                                                        │
│  MLP 9→10→2 (entrada 9 características, 10 neuronas ocultas, 2 salidas)   │
│  Entrenado en Modelo_BCI_Completo_Wav.mat                                  │
│  Clases: 0 (Mano Derecha) / 1 (Mano Izquierda)                             │
│     ↓                                                                        │
│  7. PREDICCIÓN CONTINUA                                                     │
│     ↓                                                                        │
│  Ventanas de 2 segundos, traslape 50%, predicción cada 1 segundo           │
│  Salida: clase (0 o 1) + confianza                                         │
│     ↓                                                                        │
│  8. CONTROL DE HARDWARE                                                     │
│     ↓                                                                        │
│  Enviar a ESP32 vía puerto COM3 @ 115200 baud                              │
│  Protocolo: "clase,conf,clase,conf,timestamp\n"                            │
│     ↓                                                                        │
│  9. ACTUACIÓN DE SERVOS                                                     │
│     ↓                                                                        │
│  Clase 1 (Derecha):   Dedos cerrados + Muneca a inicial                         │
│  Clase 0 (Izquierda): Dedos a inicial + Muneca pronacion                    │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

════════════════════════════════════════════════════════════════════════════════
HARDWARE (v2.0 - SIMPLIFICADO)
════════════════════════════════════════════════════════════════════════════════

MICROCONTROLADOR:
  • ESP32-WROOM-32
  • Interfaz USB: COM3 @ 115200 baud
  • 2 canales PWM @ 50 Hz, 10-bit resolution

ACTUADORES:
  • 1× Servo MG995 (dedos 1-5 simultáneamente)
    - GPIO 23
    - Rango: PWM 30 (abierto) ↔ PWM 120 (cerrado)
    - Torque: 55 kg/cm
    - Alimentación: 5V @ 2A

  • 1× Servo SG90 (muñeca pronación/supinación)
    - GPIO 17
    - Rango: PWM 90 (neutro) ↔ PWM 60 (pronación)
    - Torque: 1.5 kg/cm
    - Alimentación: 5V @ 0.5A

FUENTE DE ALIMENTACIÓN:
  • 5V @ 2.5A mínimo (para ambos servos)

════════════════════════════════════════════════════════════════════════════════
SOFTWARE PRINCIPAL: control_final.m
════════════════════════════════════════════════════════════════════════════════

FUNCIÓN:
  control_final(archivo_entrada)
  
PARÁMETROS:
  archivo_entrada: ruta a .cdt o .set
                   Ejemplo: 'C:\Desktop\Acquisition\Acquisition 15.cdt'

FLUJO AUTOMÁTICO:
  1. Valida archivo (conversión .cdt → .set si necesario)
  2. Carga EEGLAB y datos
  3. Extrae características (Welch + Burg + Wavelets)
  4. Normaliza datos
  5. Carga modelo entrenado (Modelo_BCI_Completo_Wav.mat)
  6. Hace predicciones continuas (ventanas 2 seg, traslape 50%)
  7. Abre puerto COM3 y envía predicciones a ESP32
  8. Genera gráficos de resultados

SALIDA:
  • Gráficos con predicciones en tiempo real
  • Log detallado en consola
  • Movimiento de servos (si ESP32 conectado)
  • Tiempo aproximado: 30-60 segundos (depende archivo)

MAPEO DE MOVIMIENTOS
(una clase comanda un servo; el otro vuelve a su posición inicial):

  Clase 1 (Mano DERECHA):
    → DEDOS:  Cerrados (PWM 120, cierra el puño)
    → MUÑECA: Posición inicial (PWM 90, no participa)

  Clase 0 (Mano IZQUIERDA):
    → DEDOS:  Posición inicial (PWM 30, los retrae el resorte)
    → MUÑECA: Pronación (PWM 60)

  Etiquetas según MODULO_BATCH...m línea 154: Y=1 → "lado derecho".

FLUJO TÍPICO DE USO
════════════════════════════════════════════════════════════════════════════════

SETUP INICIAL (Primera vez - 15 minutos):
  1. Instalar Arduino IDE (si no lo tienes)
     https://www.arduino.cc/en/software
  
  2. Agregar soporte ESP32 en Arduino IDE
     (Ver CARGAR_EN_ARDUINO_V2.txt para detalles)
  
  3. Cargar código esp32_bci_hand_v2.cpp en ESP32
     • Copiar código completo de esp32_bci_hand_v2.cpp
     • Crear nuevo sketch en Arduino IDE
     • Pegar código
     • Seleccionar board: ESP32-WROOM-32
     • Seleccionar puerto: COM3
     • Sketch → Upload
  
  4. Conectar hardware
     • GPIO 23 → MG995 (dedos)
     • GPIO 17 → SG90 (muñeca)
     • 5V @ 2.5A

CADA VEZ QUE ANALICES (2 minutos):
  1. Conectar ESP32 por USB (si deseas hardware)
  
  2. En MATLAB:
     >> control_final('C:\ruta\a\archivo.cdt')
  
  3. Esperar a que se complete:
     - Procesa señal
     - Entrena/carga modelo
     - Hace predicciones
     - Envía a ESP32
     - Genera gráficos

════════════════════════════════════════════════════════════════════════════════
PARÁMETROS IMPORTANTES
════════════════════════════════════════════════════════════════════════════════

PROCESAMIENTO DE SEÑAL:
  • Canales: C3, C4, Cz
  • Banda de interés: 13-30 Hz (Beta)
  • Métodos: Welch PSD, Burg PSD, Wavelets D4
  • Características: 9 dimensionales (3 métodos × 3 canales)

RED NEURONAL:
  • Arquitectura: MLP 9→10→2
  • Función activación: Sigmoid (oculta), Softmax (salida)
  • Entrenamiento: 70% training, 15% validation, 15% test
  • Época: ~200 iteraciones

PREDICCIÓN EN TIEMPO REAL:
  • Ventana: 2 segundos
  • Traslape: 50% (1 segundo de paso)
  • Predicción cada: 1 segundo
  • Latencia: ~100-200 ms

PROTOCOLO SERIAL:
  • Puerto: COM3
  • Baudrate: 115200
  • Formato: "clase_ded,conf_ded,clase_mun,conf_mun,timestamp\n"
  • Ejemplo: "1,0.87,1,0.65,1.234\n"
