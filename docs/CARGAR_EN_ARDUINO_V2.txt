════════════════════════════════════════════════════════════════════════════════
        INSTRUCCIONES PARA CARGAR CÓDIGO ESP32 v2.0 EN ARDUINO IDE
             (1× MG995 DEDOS + 1× SG90 MUÑECA)
════════════════════════════════════════════════════════════════════════════════

CAMBIOS EN v2.0:
  • 1 servo MG995 para TODOS los dedos (cerrar/abrir simultáneamente)
  • 1 servo SG90 para MUÑECA (pronación/supinación)
  • Total: 2 servos (era 6 servos en v1.0)
  • Código simplificado y optimizado

════════════════════════════════════════════════════════════════════════════════
PASO 1: PREPARACIÓN (SI NO LO HICISTE EN v1.0)
════════════════════════════════════════════════════════════════════════════════

1. Descarga Arduino IDE:
   https://www.arduino.cc/en/software

2. Instala Arduino IDE

3. Abre Arduino IDE

PASO 2: AGREGAR SOPORTE ESP32 (SI NO LO HICISTE EN v1.0)
════════════════════════════════════════════════════════════════════════════════

1. File → Preferences

2. Busca "Additional boards manager URLs"

3. Haz click en el ícono (a la derecha del campo)

4. Copia y pega esta URL:

5. Click OK

6. Tools → Board Manager

7. Busca "esp32"

8. Selecciona "ESP32" de "Espressif Systems"

9. Click "Install" (espera a completar)

10. Close Board Manager

3. Press Enter

     -> Muneca: PRONACION (PWM 60)

Si ves estos mensajes → ✓ ¡CÓDIGO FUNCIONA CORRECTAMENTE!

════════════════════════════════════════════════════════════════════════════════
PASO 9: CONEXIÓN DE HARDWARE
════════════════════════════════════════════════════════════════════════════════

DEDOS (MG995) en GPIO 23:
  Rojo (5V)     → Pin VIN del ESP32
  Negro (GND)   → Pin GND del ESP32
  Amarillo (Señal) → GPIO 23

MUÑECA (SG90) en GPIO 17:
  Rojo (5V)     → Pin VIN del ESP32
  Negro (GND)   → Pin GND del ESP32
  Amarillo (Señal) → GPIO 17

FUENTE DE ALIMENTACIÓN:
  5V @ 2A mínimo

════════════════════════════════════════════════════════════════════════════════
PASO 10: USAR CON MATLAB
════════════════════════════════════════════════════════════════════════════════

En MATLAB, ejecuta el script maestro:

    >> control_final('C:\ruta\al\archivo.cdt')
    
    o
    
    >> control_final('C:\ruta\al\archivo.set')

El script:
  1. Procesará el archivo
  2. Extraerá características
  3. Entrenará/cargará el modelo
  4. Hará predicciones
  5. Enviará comandos a COM3
  6. Los servos se moverán automáticamente

════════════════════════════════════════════════════════════════════════════════
MAPEO DE CONTROL
════════════════════════════════════════════════════════════════════════════════

Predicción = 1 (Mano DERECHA):
  → Dedos: CERRADOS (PWM 120, cierra el puño)
  → Muñeca: POSICIÓN INICIAL (PWM 90, no participa)

Predicción = 0 (Mano IZQUIERDA):
  → Dedos: POSICIÓN INICIAL (PWM 30, los retrae el resorte)
  → Muñeca: PRONACIÓN (PWM 60)

Cada clase comanda un solo servo; el otro vuelve a su posición inicial.
Etiquetas según MODULO_BATCH...m línea 154: Y=1 → "lado derecho".

════════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

❌ "COM3 no aparece"
   → ¿ESP32 está conectado por USB?
   → Device Manager → Puertos → Busca "USB Serial"
   → Instala driver si es necesario:
     https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers

❌ "Error de compilación"
   → Verifica que copiaste TODO el código
   → Busca la línea que falta y cópiala
   → Vuelve a intentar Upload

❌ "Serial Monitor muestra caracteres raros"
   → Verifica baudrate: debe ser 115200
   → Presiona botón RESET en ESP32
   → Cierra y abre Serial Monitor

❌ "Servos no se mueven"
   → ¿Datos llegan a Serial Monitor?
   → ¿5V en el pin VIN del ESP32?
   → ¿Servos conectados correctamente?
   → Prueba movimiento manual con Serial Monitor
