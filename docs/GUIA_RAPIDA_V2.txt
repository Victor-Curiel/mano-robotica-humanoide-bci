TROUBLESHOOTING RÁPIDO
════════════════════════════════════════════════════════════════════════════════

❌ "Error: Puerto COM3 no se abre"
   → ¿ESP32 conectado?
   → Device Manager → Busca "USB Serial"
   → Instala driver: https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers

❌ "Error: Modelo no encontrado"
   → Ejecuta MODULO_BATCH_EXTRACCION_WELCH_Y_BURG_50TRASLAPE_PLOT.m
   → Esto genera Modelo_BCI_Completo_Wav.mat

❌ "Servos no se mueven pero código sube OK"
   → ¿5V en pin VIN del ESP32?
   → ¿Servos conectados a GPIO 23 y 17?
   → ¿Conector de masa común?
   → Prueba en Serial Monitor: 1,0.5,1,0.5,1
